## 2. Методика экспериментальной оценки эффективности

### 2.1. Гипотезы

- **H1.** Время документирования осмотра (от начала осмотра до готового отчёта) с Inspecto меньше, чем при ручном процессе.
- **H2.** Число ошибок сопоставления фотографий с дефектами с Inspecto меньше.
- **H3.** Время поиска информации о прежних дефектах при повторном осмотре с Inspecto меньше.
- **H4.** Удобство использования Inspecto оценивается не ниже «приемлемого» уровня по шкале SUS.

### 2.2. Условия

| Параметр | Значение |
|---|---|
| Сравниваемые процессы | Ручной: камера телефона + заметки + сборка отчёта в текстовом редакторе по шаблону. Inspecto: Android-приложение + PDF |
| Объект | Одно и то же помещение (или подготовленный набор фотосцен) с заранее известным эталонным списком из N дефектов (N ≈ 10–15), разных категорий и серьёзности |
| Участники | 5–8 человек; фиксируются опыт осмотров и опыт работы со смартфоном |
| Дизайн | Внутрисубъектный (каждый участник выполняет оба процесса); порядок процессов чередуется между участниками для компенсации эффекта обучения |
| Повторный осмотр | Через перерыв: часть эталонных дефектов «устранена» (изменена сцена), добавлены новые |
| Инструктаж | Одинаковый письменный сценарий для обоих процессов |

### 2.3. Измеряемые показатели

| Показатель | Способ измерения |
|---|---|
| Время заполнения чек-листа и регистрации дефектов | Секундомер / журнал событий приложения |
| Время подготовки отчёта | От окончания осмотра до готового PDF |
| Ошибки сопоставления фото и дефектов | Сравнение отчёта с эталоном: фото у не того дефекта, дефект без фото, пропущенный дефект |
| Время поиска при повторном осмотре | Время ответа на набор вопросов о прежних дефектах |
| Удобство | Анкета SUS (10 вопросов, балл 0–100) после работы с Inspecto |

### 2.4. Обработка

- Описательная статистика (медиана, межквартильный размах) для каждого показателя и процесса.
- Парное сравнение: критерий Уилкоксона для связанных выборок (малая выборка, без предположения о нормальности); уровень значимости 0,05; приводится размер эффекта.
- Сырые данные хранятся в `platform/research/experiment/` в обезличенном виде.

### 2.5. Ограничения (заранее)

- Малая выборка — выводы предварительные.
- Автор системы проводит эксперимент — риск предвзятости; снижается фиксированным сценарием и эталоном.
- Подготовленный объект упрощает реальные условия.
