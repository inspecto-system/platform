# Модель угроз Inspecto

> Метод: STRIDE по элементам потоков данных. Версия 0.2 — ревизия CP5 (T-506, 2026-11-09), см. раздел 6. Следующий пересмотр — перед CP7.
> Меры подробно — [SECURITY.md](SECURITY.md).

## 1. Активы

| Актив | Ценность |
|---|---|
| Учётные данные и токены | Полный доступ к данным пользователя |
| Персональные данные: email, ФИО, адреса объектов | Конфиденциальность, требования 152-ФЗ |
| Фотографии помещений | Конфиденциальность (вид жилья, ценности, планировка) |
| Результаты осмотров и PDF-отчёты | Целостность и юридическая значимость (споры при приёмке) |
| Закрытый ключ подписи JWT, секреты сервисов | Компрометация всей системы |
| Доступность системы во время осмотра | Срыв осмотра на объекте |

## 2. Нарушители

| Нарушитель | Возможности |
|---|---|
| Внешний анонимный | Доступ к публичному API через интернет, автоматизированные атаки |
| Зарегистрированный пользователь | Валидный токен; попытки доступа к чужим данным (IDOR), загрузка вредоносных файлов, внедрение данных в отчёты |
| Злоумышленник с украденным токеном или устройством | Действия от имени пользователя до истечения или отзыва токена |
| Злоумышленник, получивший доступ к одному сервису | Попытка горизонтального перемещения к другим сервисам и базам |
| Читатель публичных репозиториев | Поиск секретов и уязвимостей в коде |

## 3. Границы доверия

1. Интернет ↔ nginx (недоверенный клиент).
2. nginx ↔ сервисы (внутренняя сеть `app`).
3. Сервисы ↔ PostgreSQL и SeaweedFS (сеть `data`).
4. report-service ↔ Gotenberg (сеть `render`, без интернета).
5. Устройство Android ↔ его локальное хранилище (черновики, токены).

## 5. Принятые риски

| Риск | Обоснование | Пересмотр |
|---|---|---|
| Нет TLS между сервисами внутри docker-сети в MVP | Сервисы в изолированных внутренних сетях одного хоста; межсервисные вызовы аутентифицированы | Этап расширения (развёртывание на VPS) |
| Access-токен действует до 15 минут после отзыва сессии | Компромисс между производительностью и мгновенным отзывом | При появлении требований к мгновенному отзыву |
| PDF не подписывается электронной подписью | Не требуется для MVP | Этап расширения |
| Предупреждения OWASP ZAP 10049 (Non-Storable Content) и 10109 (Modern Web Application) | Страницы и ответы API для вошедшего пользователя не должны кэшироваться; 10109 — справочное | При пересмотре правил `deploy/zap/rules.tsv` |

Статусы изменены только там, где мера подтверждена проверкой; остальные угрозы на CP5 не пересматривались и сохраняют статус «П» до ревизии перед CP7.
